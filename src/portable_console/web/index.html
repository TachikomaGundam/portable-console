Data-Driven Console

Everything on this page renders from what the machine actually reports: service links come from /api/links, and GPU / fan / power / disk / control blocks appear only when the matching keys exist in /health.json or /api/cards. On a plain laptop you get Server Load and links; on a GPU workstation the full telemetry appears. No hostname or port is baked in — the console works on any host, via LAN, VPN, or localhost.
